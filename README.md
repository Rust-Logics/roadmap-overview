Semana 1: Introdução e Configuração do Ambiente  
**Objetivos:**  
- Instalar o Rust com o rustup  
- Configurar um editor (recomenda-se VS Code com Rust Analyzer)  
- Criar e executar o programa “Hello, World!”  
- Ler os primeiros capítulos de *The Rust Programming Language* (“The Book”) para ter uma visão geral da linguagem  

**Atividades:**  
- Dedicar 1–2 horas para instalação e primeiros testes  
- Marcar uma reunião breve para alinhar dúvidas sobre a configuração e discutir o que foi lido  

**Recursos Chaves:**  
- Livro *The Rust Programming Language* (Português): [link](https://rust-br.github.io/rust-book-pt-br/ch01-01-installation.html)  
- Tutorial Oficial de Instalação do Rust (rustup): [link](https://www.rust-lang.org/tools/install)  
- Vídeo – Introdução e Instalação do Rust (exemplo): [*Introdução à linguagem Rustlang | Aprenda Rust | 01* ](https://youtu.be/zWXloY0sslE?si=QrPktB48UVN1EkCg)

Semana 2: Variáveis, Tipos de Dados e Operadores  
**Objetivos:**  
- Entender declaração de variáveis (imutáveis e mutáveis)  
- Conhecer os tipos primitivos (inteiros, floats, booleans, etc.)  
- Praticar operadores aritméticos, relacionais e lógicos  

**Atividades:**  
- Resolver exercícios simples (ex.: converter temperaturas, cálculos básicos)  
- Cada participante pode compartilhar uma solução simples em um chat ou reunião online  

**Recursos Chaves:**

Semana 3: Controle de Fluxo – Condicionais e Laços  
**Objetivos:**  
- Estudar estruturas condicionais: `if`, `else`, e o uso de `match`  
- Trabalhar com laços: `loop`, `while` e `for`  

**Atividades:**  
- Programar pequenos desafios (ex.: verificar se um número é par/ímpar, contagem regressiva)  
- Discutir em grupo as melhores abordagens para esses problemas  

**Recursos Chaves:**  
- Capítulo 3.5 – Controle de Fluxo (*The Book*, Português): [link](https://rust-br.github.io/rust-book-pt-br/ch03-05-control-flow.html)

Semana 4: Estruturas de Dados Básicas e Tipos Customizados  
**Objetivos:**  
- Utilizar arrays, vetores (`Vec`) e strings em Rust

**Atividades:**

Semana 5: Funções, Closures e Modularização  
**Objetivos:**  
- Entender a definição de funções: parâmetros, retorno e escopo  
- Explorar funções anônimas (*closures*) e quando utilizá-las  
- Organizar o código dividindo-o em módulos (usando o Cargo)  

**Atividades:**  
- Refatorar um código simples (por exemplo, o código da semana 4) para usar funções bem definidas  
- Montar um pequeno projeto com dois ou três módulos (arquivos separados) e discutir a estrutura

Semana 6: Algoritmos Simples e Resolução de Problemas  
**Objetivos:**  
- Revisitar a lógica de programação com problemas clássicos  
- Implementar algoritmos como:  
  - Fatorial de um número  
  - Sequência de Fibonacci  
  - Inversão de uma string  

**Atividades:**  
- Dividir problemas entre os participantes e comparar soluções  
- Discutir a decomposição dos problemas em passos menores  

**Recursos Chaves:**

Semana 7: Algoritmos de Ordenação e Busca  
**Objetivos:**  
- Implementar algoritmos de ordenação (ex.: *Bubble Sort* e *QuickSort*)  
- Implementar buscas (*busca linear* e *busca binária*)  
- Introduzir noções básicas de análise de complexidade (*notação Big O*)  

**Atividades:**  
- Codificar os algoritmos e testar com diferentes conjuntos de dados  
- Fazer uma breve sessão para discutir qual algoritmo funciona melhor em cada cenário

Semana 8: Ownership, Borrowing e Lifetimes  
**Objetivos:**  
- Estudar os conceitos centrais do Rust que garantem segurança de memória  
- Compreender como o sistema de propriedade evita erros comuns  

**Atividades:**  
- Resolver exercícios práticos que envolvam transferência de propriedade e empréstimo (*borrowing*)  
- Analisar exemplos onde *lifetimes* são explicitados para reforçar a compreensão  

**Recursos Chaves:**  
- Capítulo 4 – Ownership (*The Book*, Português): [link](https://rust-br.github.io/rust-book-pt-br/ch04-00-understanding-ownership.html)  
- Capítulo 10.3 – Syntax de Lifetimes (*The Book*, Português): [link](https://rust-br.github.io/rust-book-pt-br/ch10-03-lifetime-syntax.html)  

---  

Semana 9: Programação Funcional com Iterators e Closures  
**Objetivos:**  
- Explorar o uso de *iterators* e métodos funcionais como `map`, `filter` e `fold`  
- Refatorar algoritmos já feitos para um estilo mais funcional e conciso  

**Atividades:**  
- Escolher um ou dois algoritmos anteriores (por exemplo, o de ordenação ou Fibonacci) e reescrevê-los usando *iterators* e *closures*  
- Discutir em grupo as vantagens de um estilo funcional  

**Recursos Chaves:**  
- Capítulo 13 – Closures (*The Book*, Português): [link](https://rust-br.github.io/rust-book-pt-br/ch13-00-functional-features.html)  
- Artigo/Tutorial – Iterators em Rust: [link](https://dev.to/francescoxx/iterators-in-rust-fm)

Semana 10: Projeto Prático e Revisão Geral  
**Objetivos:**  
- Integrar os conceitos estudados em um projeto final (ex.: uma aplicação CLI)  
- Praticar testes e refatoração do código  

**Atividades:**  
- Planejar, em grupo, as funcionalidades do projeto (entrada de dados, processamento, saída)  
- Dividir tarefas para implementação e depois reunir para revisão e testes  
- Se o tempo permitir, uma breve introdução à concorrência ou programação assíncrona
